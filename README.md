# Химический шпион 🧪

**Химический шпион** — это вечеринка с элементами химии! Популярная игра «Шпион» теперь в химической обёртке: соберите друзей, передавайте телефон и выясните, кто из вас шпион, а кто знает загадочный химический элемент.

## 📱 Платформа

Приложение разработано **исключительно для Android**.

📥 **[Скачать последний релиз (v1.0)](https://github.com/Pidroyder/chemistry-imposter/releases/tag/v1.0)** — APK-файл находится в разделе Releases.

## 🎮 Как играть

1. Введите количество игроков (минимум **3**)
2. Передавайте телефон по кругу — каждый узнает свою роль
3. **Мирные жители** получают название химического элемента (водород, кислород, золото и ещё 110+ элементов таблицы Менделеева!)
4. Один игрок — **шпион**, он не знает элемент
5. Обсуждайте, задавайте вопросы и вычисляйте шпиона!

## ✨ Особенности

- 🔬 Более **110 химических элементов** с названиями на русском
- 📱 Простой и понятный интерфейс
- 👥 Поддержка любого количества игроков от 3 человек
- 🎉 Идеально для вечеринок, уроков химии и семейных вечеров
- 🚫 Никакой рекламы и лишних отвлечений

## 🛠️ Технологии

- Python
- KivyMD
- Buildozer (сборка APK)

## 📂 Структура проекта

- `main.py` — точка входа, интерфейс приложения
- `chemistryimposter.kv` — разметка интерфейса (Kivy)
- `randomizer/chooser.py` — логика игры: выбор элемента и шпиона
